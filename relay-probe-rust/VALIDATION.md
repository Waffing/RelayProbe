## Windows Fake-IP 实测

验收时 Mihomo 正在运行，系统 DNS 将 `example.com` 解析到 `198.18.x.x`。在 `ALLOW_PRIVATE_TARGETS=false` 下，Rust 与 Python 两版通过 `/api/models` 测试同一 HTTPS 域名。关闭兼容时返回 `400` 和 `local_network_compat`。开启后均完成 TLS 并保留目标站返回的 `404`。该域名仅用来验证连接，模型列表和正常探针响应使用本地模拟站完成验收。

新增回归验证 HTTPS 域名与 Fake-IP 地址组合，并验证直接填写 Fake-IP、内网、回环、链路本地和混合 DNS 结果时的拦截。回环代理需要显式填写并启用本机兼容。
